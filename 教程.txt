让 Claude Code 住进一块小板子(完整教程)

桌上这块小屏幕,说话的是我自己服务器上 Claude Code 里面的对话。
对话记录、工具等都能够完整使用。

整条链路:
板子 → 服务器(语音网关 → Telos 后端 → Claude Code) → 板子
声音的识别和合成走的是阿里云,大脑是 Claude 订阅。

代码已开源:
github.com/airem2024/voice-terminal(网关,固件在 Releases)
github.com/airem2024/telos(后端+手机App,App 在 Releases)

  参考费用:我这两天调试加日常对话一共 2.4 元,话痨每月大概 30~50
· 一台电脑 + USB 数据线:只用一次,把板子指向你的服务器
· 半天时间

  或家里旧电脑/树莓派(省月费,要魔法自己想办法,还得真的不关机。

  或买个域名(几十块一年,配 Cloudflare 托管)

━━ 食用方式一:一步一步走 ━━━━━━━━

一共四层,按顺序装。每层末尾有个验证点,过了再往下,
出问题时你知道是哪一层的问题。

── 第 1 层:机器和 Claude Code ──

先选一条路,后面三层的写法略有不同:

  A. 海外 VPS —— 省心。24 小时开着,网络问题一次解决
  B. 家里的电脑/树莓派 —— 省月费,但要魔法、要真的不关机

【A. VPS】

买台 VPS(2G 内存起,能访问 Anthropic 就行),ssh 上去。

装 Node(用系统源,别用 nvm——后面 systemd 服务会被 nvm 的路径坑):
  curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
  apt install -y nodejs

装 claude code:
  npm install -g @anthropic-ai/claude-code

【B. 家里的电脑】

Windows:装 WSL2(管理员开 PowerShell 跑 wsl --install,重启),
然后在 WSL 的 Ubuntu 里照 A 的命令走一遍。
别在 Windows 原生装——后面 Telos 的部署脚本是 bash 的,跑不了。

Mac / Linux 桌面:直接装 Node 和 claude code(Mac 用 brew install node)。
后面部署脚本能跑,只是装不了系统服务,得手动跑,见第 2 层。

树莓派:就是 Linux,照 A 走。

家里部署的两个附加事项:
· 魔法要在整机层面生效,不能只给浏览器挂——claude 是命令行程序,
  它得能直连 Anthropic
· 电脑关机 = 板子下线,这条没有绕过的办法

【两条路都一样:登录】

跑一下 claude,选订阅登录,它给你一个网址——复制到浏览器打开,
授权后把页面给的码粘回终端。
接 api 就不用登录,设环境变量 ANTHROPIC_API_KEY 即可。

验证点:终端里 claude 能回你话。

── 第 2 层:Telos 后端 ──

  git clone https://github.com/airem2024/telos
  cd telos && bash server/deploy.sh

脚本会装依赖、生成 token(记下来,后面都靠它)、装 systemd 服务。

家里的电脑(WSL / Mac)没有 systemd,加个参数:
  bash server/deploy.sh --no-svc
它只装依赖和生成 token,然后自己跑:
  cd server && node server.js
这个终端窗口得一直开着。想关窗口也能跑的话,WSL 用 nohup,
Mac 用 pm2 或 launchd——不折腾就先开着窗口,能用就行。

三个坑:
· 一定先把上一层的 claude 登录弄好再跑 deploy——脚本发现没装
  claude 只是警告不拦,服务照样起,然后每句话都失败
· 需要 sudo(装服务用)
· 哪个用户跑 deploy,就得是哪个用户登录的 claude

远程访问要个加密隧道(手机/浏览器用,板子不走这条):
  cloudflared tunnel --url http://127.0.0.1:8790
一条命令给你一个临时 https 地址。

验证点:curl http://127.0.0.1:8790/version 返回 JSON 就是活了。
更直观的验法:浏览器打开隧道地址,是一个完整的网页版,填 wss
地址和 token,直接聊一句。通了这层就完事,不用装 App。

── 第 3 层:语音网关 ──

  git clone https://github.com/airem2024/voice-terminal
  cd voice-terminal && npm install
  cp config.example.json config.json

config.json 每个键上面都有说明,必填的这几样:
· dashscopeEnvFile:指向一个文件,里面一行 DASHSCOPE_API_KEY=sk-xxx
  (key 在百炼控制台创建)
· deviceAllow:板子的 MAC 地址(不知道就先留空,板子连一次看日志)
· bindHost + publicWsUrl / publicHttpUrl:看你走哪条路,见下

【A. VPS】板子从公网连回来

bindHost 保持默认 127.0.0.1,前面用 nginx 反代 80 端口:

  server {
    listen 80;
    location / {
      proxy_pass http://127.0.0.1:8791;
      proxy_http_version 1.1;
      proxy_set_header Upgrade $http_upgrade;
      proxy_set_header Connection "upgrade";
    }
  }

publicWsUrl 填 ws://你的IP/,publicHttpUrl 填 http://你的IP/。

为什么非要 80 端口:板子装不了任何代理,而且实测部分家庭网络到
高位端口时通时不通,标准端口最稳。明文的取舍是省掉板子的加密
开销,代价是语音明文过公网,自己权衡。

【B. 家里的电脑】板子和它同一个 WiFi,直接局域网连

这条路简单得多——不用公网、不用域名、不用 nginx:
· bindHost 填 "0.0.0.0"
· publicWsUrl 填 ws://电脑的局域网IP:8791/
· publicHttpUrl 填 http://电脑的局域网IP:8791/

局域网 IP 怎么看:Windows 在 WSL 里跑 ipconfig.exe 找 IPv4,
Mac 系统设置里看,Linux 跑 ip a。一般是 192.168.x.x。
最好在路由器里给电脑绑个固定 IP,不然重启后 IP 变了板子就找不着。
⚠️bindHost 填 0.0.0.0 等于把控制台暴露给整个局域网(有 token 挡着),
别在公共 WiFi 下这么干。

【两条路都一样】

跑起来:node index.js
(VPS 稳定后可以包个 systemd 服务;家里电脑同上,窗口开着就行)

验证点:浏览器开控制台,能看到页面。
  VPS:    http://你的IP/admin?t=你的boardToken
  家里:   http://局域网IP:8791/admin?t=你的boardToken
boardToken 在 config.json 里,首次启动自动生成。

── 第 4 层:板子 ──

板子保持出厂固件,USB 连电脑:

  cd voice-terminal/tools
  (把 gateway.env.example 复制成 gateway.env,填网关地址和 boardToken)
  pip install esptool esp-idf-nvs-partition-gen requests pyserial
  python flash.py seturl

一条命令,把"去哪拿配置"写进板子,其余什么都不动。
(Windows 不知道怎么在这个目录开命令行:文件管理器进到 tools
文件夹,地址栏输入 cmd 回车。)

烧完板子重启,WiFi 会被清掉,重新配一次——这是正常的不是坏了。
配完它自己去你的网关拿配置,服务器地址和 token 都在里面。

验证点:按一下侧键,说句话,它回你。到这全通了。

最后一件事:打开控制台,在"附着对话"里选一个你聊过的对话。
不选的话板子接的是全新空白会话——里面没有你的任何记录。

── 让她成为她(可选) ──

· 附着对话决定接电话的是谁。你在手机/网页上聊出来的对话,
  控制台里选中,板子接的就是它,记忆是同一份
· 音色:百炼控制台的声音复刻,录一段样本拿到音色 id,
  填进 config.json 的 voice
· 名字:控制台"唤醒语"卡片,输中文自动转拼音,多音字可以手改

── 换表情(可选) ──

屏幕上那 21 张脸在 assets 分区,和固件是分开的,能整套换成自己的。
仓库 tools/assets.py 三条命令搞定:

  python assets.py unpack assets.bin my_faces/   拆出全部表情
  python assets.py pack   my_faces/ my.bin       换完图重新打包
  python assets.py flash  my.bin                 烧回板子

官方 assets.bin 从微雪 wiki 下载,或者直接从自己板子里读出来:
  esptool read_flash 0x920000 0x300000 assets.bin

图的要求:64×64 PNG,文件名不变。太大了 pack 会直接报错,
不会让你烧出一个坏包。刷坏了最多没表情,不影响开机,
刷回官方包就恢复。

── 第 5 步(可选):唤醒词 ──

喊一声名字就开始对话,不用按键。两个东西:
· 服务器下个识别模型(36MB,命令在仓库 README 唤醒词那节)
· 板子刷配套固件:voice-terminal 仓库 Releases 的 fw-v2.5.0,
  esptool 刷法写在 Release 页。只写应用分区,WiFi 和地址不动。
  只用按键对话就不用刷
